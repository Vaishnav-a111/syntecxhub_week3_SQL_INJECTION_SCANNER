# SQL Injection Scanner

## Description
This project is a Python-based SQL Injection vulnerability scanner developed for cybersecurity learning purposes.

The scanner:
- Tests URLs using SQL injection payloads
- Detects common SQL error messages
- Generates vulnerability reports
- Uses threading and rate limiting

## Technologies Used
- Python
- Requests Library
- Multithreading

## Features
- SQL Injection Detection
- Error Detection
- Report Generation
- Concurrency Support
- Rate Limiting

## How to Run

Install requirements:

pip install -r requirements.txt

Run scanner:

python scanner.py

## Warning
This tool is created strictly for educational purposes and authorized testing environments only.

## Testing Environment

The scanner was tested on a locally hosted vulnerable Flask application created for ethical cybersecurity practice and SQL injection detection testing.
